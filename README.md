# S3 Clone – File Uploader

## Project Overview
This project simulates **AWS S3** functionality by providing a simple **file uploader** using **Node.js** and **Express**. The app allows users to upload files (images, documents, etc.) to a server, mimicking how **AWS S3** would handle file storage.

---

## Features
- **File Upload**: Allows users to upload files through a simple frontend.
- **Local Storage Simulation**: Files are stored locally in the `uploads/` directory (or Firebase Storage for a real cloud-based solution).
- **API Endpoint**: Mimics AWS S3 upload functionality through an API route for file uploading.
- **Frontend**: Simple HTML, CSS, and JavaScript interface to interact with the backend.

---

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **File Handling**: Multer (for file upload handling)
- **Cloud Storage**: Local (simulating AWS S3)
